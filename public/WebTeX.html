Compilazione

        
Indica dove WebTeX deve cercare i binari del compilatore. Il campo e' opzionale: se resta vuoto viene usato il PATH del backend.

        

          Tipo progetto riconosciuto
          LaTeX
        

        

          Percorso dei binari LaTeX
          
          
Se vuoto usa il PATH del backend; compila con eseguibili come pdflatex xelatex lualatex.

        

        

          Parametri LilyPond
          
          
Inseriti tra lilypond e il file .ly; sono supportiti valori tra virgolette. La destinazione resta gestita da WebTeX.

        

        

          Formato di output LilyPond
          
          
PNG, SVG e partiture con più blocchi possono produrre più artefatti nella cartella output/.

        

        

          Comando richiesto al backend
          pdflatex
        

        

          Pipeline di compilazione
          
          
Gli output vengono sovrascritti nella cartella output/ del progetto.
